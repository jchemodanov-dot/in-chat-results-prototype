# Reveal Flow — кинематографичный продающий разбор после AI-сессии

> Реализовано в прототипе (`src/flow/`). Светлый, игровой, эмоциональный флоу
> из сменяющихся экранов с переходами, иллюстрациями-персонажами и анимациями.
> Цель: не «карточка-paywall», а захватывающий путь, который продаёт следующий
> шаг. Адаптируется под 6 тем сессии. Демо-переключатель тем — слева вверху.

## Почему флоу, а не одна карточка

Одна статичная карточка информирует, но не вовлекает. Сильные продуктовые
онбординги (Duolingo, Fabulous, fitness/quiz-apps) продают через **движение по
экранам**: сегменты прогресса сверху, по одному эмоциональному биту на экран,
кнопка «Дальше», нарастание к кульминации-офферу. Это и собрано.

## Структура (6 экранов)

| # | Экран | Что происходит | Эмоция |
|---|-------|----------------|--------|
| 0 | **Скан** | маскот-звёздочка «слушает», бегущие строки «Слушаю тебя… / [тема] / Собираю разбор…», пульс-кольца, авто-переход | «меня слышат» |
| 1 | **Раскрытие** | конфетти-взрыв, иллюстрация впрыгивает, badge + жирный заголовок «Мы нашли важную нить» | «бам, это про меня» |
| 2 | **Инсайт** | крупный бережный summary состояния | «меня поняли» |
| 3 | **Путь-квест** | иллюстрация горы с тропой + 3 ступени каскадом на «нити» → флажок-цель | «есть структура и маршрут» |
| 4 | **Трансформация** | карточки «[из] → [в]» с пружинным переходом | «я хочу туда» |
| 5 | **План (оффер)** | конфетти, «план готов 🎉», ценности с галочками зажигаются по очереди, дышащая кнопка «Открыть мой план» | «продолжение уже готово, беру» |

Навигация: кнопка «Дальше» / тап по экрану — вперёд; шеврон ← назад; скан
авто-переходит. Сегменты прогресса сверху — как в сторис/онбординге.

## Анимации (framer-motion + CSS)

- Переходы экранов — пружинный слайд+фейд (`AnimatePresence`).
- Вход элементов — staggered spring (badge pop, иллюстрация scale-in, текст fade-up).
- **Конфетти** на раскрытии и плане (`Confetti.tsx`).
- Плавающие световые частицы (`Particles.tsx`), пульс-кольца на скане.
- Дышащая CTA на финале (`cta-breathe`), shimmer-хелперы.
- Все ключевые анимации — `src/index.css` (keyframes) + framer-motion в экранах.

## Иллюстрации (gpt-image-2)

8 иллюстраций сгенерированы через OpenAI Image API и лежат в `src/assets/flow/`:
`scan` (маскот-звезда), `journey` (гора+тропа+флаг), и по одной на тему:

| Тема | Метафора | Акцент |
|------|----------|--------|
| relationships | два пазла обнимаются, сердечки | орхидея `#A86BCB` |
| anxiety | тучка → солнышко, выдох | синий `#5784D8` |
| burnout | цветок оживает под солнцем | амбер `#CC8A45` |
| self-esteem | в зеркале — сияющая звезда-«я» | фиолет `#7A6BE3` |
| loneliness | два островка тянутся к сердцу | тил `#3FA396` |
| boundaries | герой со щитом | индиго `#5C63CC` |

Стиль: дружелюбный флэт, тёплый, не клинический. Перегенерация:
`$env:OPENAI_API_KEY=…; node scripts/gen-illustrations.mjs [id]`
(ключ читается из env, в код не пишется). `gpt-image-2` **не** поддерживает
`background:transparent` → фон у картинок пастельный.

## Контент-система (адаптив под темы)

Весь текст и акцент берутся из `src/content/themes.ts` (одна структура,
6 наборов). Поля: `scanLine, badge, headline, summary, steps[3], outcome,
from, to, lockedItems[4], lockedSubline, cta, accent`. Один hex-акцент на тему
→ все оттенки через `color-mix` (`--accent`). Добавить тему = добавить объект.

Тон-чеклист (зашит в копирайт): только «похоже / мы заметили / разберём /
поможем понять». Запрещено: «диагноз», «расстройство», «с тобой что-то не так».

## CTA и A/B (что тестировать)

CTA адаптивна под состояние: «Открыть мой план» / «Вернуть силы» / «Разобрать
тревогу». Гипотезы для теста:

1. Флоу из экранов vs одна скролл-карточка → conversion to paid, completion.
2. Со сканом-«анализом» vs сразу раскрытие → time-to-CTA, CTR.
3. Путь-квест (экран 3) vs плоский список → scroll/engagement, CTR.
4. Экран трансформации «из→в» вкл/выкл → view→purchase.
5. Текст CTA: «Открыть мой план» vs «Узнать, что делать дальше».
6. Конфетти/празднование вкл/выкл → ощущение ценности, CTR.

Метрики: CTR по CTA · conversion to paid · time on flow · drop-off по экранам
(сегменты прогресса дают воронку) · paywall view→purchase · completion next session.

## ТЗ для дизайнера / Figma

- Frame mobile 390×844. Сегменты прогресса сверху, шеврон назад, CTA снизу.
- Токен `accent` (1 цвет/тема) → тинты `color-mix(accent, white)` 7/12/15/20%.
- Типографика Inter: badge 13/700, headline 27/800 (переносится в 2 строки на
  390!), summary 22/600, step 14/500, CTA 16.5/700.
- Компоненты: `FlowProgress`, `Illustration` (rounded sticker + accent-glow),
  экраны Scan/Reveal/Insight/Journey/Transform/Plan, `Confetti`, `Particles`.
- Соответствие коду: `src/flow/*`, `src/content/themes.ts`, `src/index.css`.
- Быстрые тесты без редизайна: тексты экранов, порядок экранов, CTA — это данные.
